# 八数码益智游戏与自动求解系统
实验目标：实现状态保存、成绩记录及自动求解的八数码游戏。
基础功能：
1. 用 GUI 展示 3×3 棋盘，支持合法移动 ；
2. 提供新游戏、重新开始、步数统计和计时 ；
3. 保存游戏进度、完成记录和排行榜 ；
4. 从目标状态随机合法移动，生成可解题目 。

建议数据表：玩家表、题目表、游戏记录表、存档表。
面向对象提高项：设计棋盘类、游戏控制类、存档服务类和求解器类。
AI 提高项：A* 搜索。实现自动求解和单步提示，使用不计空格的曼哈顿距离等启发函数；
展示求解步数、搜索节点数，支持逐步播放解答。
检查重点：基础游戏可完整游玩；求解处理重复状态，对手动输入局面检查可解性。

## 环境与安装
- Python 版本
- SQL Server 2022
- ODBC Driver 18 for SQL Server
- pip install -r requirements.txt
- 数据库名：EightPuzzleDB

## 数据库配置
- 四张表：Players、Puzzles、GameRecords、GameSaves
- DB_CONNECTION_STRING 的配置方式
- 棋盘状态格式：123456780，0 表示空格

## 功能流程
1. 输入昵称，获得 player_id
2. 选择难度
3. 从终局随机合法移动 N 次，生成可解 initial_state
4. 插入 Puzzles，获得 puzzle_id
5. 游戏中仅在手动保存/自动保存时写入 GameSaves
6. 通关后写入 GameRecords
7. 查询排行榜

## AI 求解
- A* 搜索
- 曼哈顿距离
- 单步提示与自动播放
- 用户干预后取消旧路径，并重新求解
- 手动输入局面先判断合法性与可解性
